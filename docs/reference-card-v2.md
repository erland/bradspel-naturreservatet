# Visuellt referenskort

Referenskortet visar alla sex djurkrav med samma färger och SVG-ikoner som landskapsbrickorna.

## Symboler

- Färgade naturfält motsvarar Skog, Sjö, Äng, Berg och Våtmark.
- `?` betyder valfri naturtyp.
- Diagonaler räknas inte som intill.
